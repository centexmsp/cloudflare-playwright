# Cloudflare Playwright Security Fork

This is a security-hardened fork of Cloudflare's Playwright for OSINT platform browser isolation.

## Security Standards Applied

- Repository security standards from osint-platform
- Automated security scanning via GitHub Actions
- Code quality enforcement via pre-commit hooks
- Defense-in-depth security practices

## Integration

This fork is integrated as a Git submodule in the osint-platform project.

See: https://github.com/centexmsp/osint-platform

## Browser Isolation

Used for secure web scraping and data collection in OSINT operations using Cloudflare Browser Rendering API.
